# Changelog

## 0.4.0
- Added dedicated face geometry pipeline with constrained local warps.
- Added body geometry pipeline driven by external pose/person-mask data.
- Added explicit eye/nose/mouth/chin geometry controls.
- Added non-destructive heal point API with soft patch blending.
- Added threaded execution to geometry/heal passes.
- Preserved C ABI compatibility by adding new entry points rather than removing old ones.

## 0.3.0
- Advanced color, AI provider seam, parallel execution and Vulkan capability layer.

## 0.2.0
- Render graph, masks, analyzer, presets, face warp and skin processing.
