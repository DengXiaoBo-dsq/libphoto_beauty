# v0.4 geometry and retouching

## Face geometry
The engine exposes additive geometry controls for face slimming, jaw width, chin length,
eye scale/vertical/spacing, nose scale/bridge and mouth scale/vertical. The pipeline uses
inverse local warps with a soft face boundary so the edit fades into the surrounding image.

Dense 468-point inputs are accepted through the existing face-data ABI; the indices used by
the built-in geometry pass are mapped to stable semantic anchors. A dedicated learned dense-mesh
module remains a future model-backed pass.

## Body geometry
The public body ABI accepts pose points plus an optional person mask. The built-in reference pass
uses torso/hip/leg bands and the mask to keep deformation localized to the subject. The consumer
must keep `PBEBodyData` buffers alive until the current render call returns.

## Healing
`pbe_set_heal_points` accepts normalized soft repair points. The reference pass samples a nearby
ring around each point and blends it with a smooth falloff. Production model-backed inpainting can
replace this pass without changing the public image API.
